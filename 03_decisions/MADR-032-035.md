## MADR-034：iPhone 键盘只兑换短期插入授权

- Status：ACCEPTED FOR IMPLEMENTATION；用户系统授权、签名和端侧验证仍单独完成。
- Options：仅主 App 查看后手动转录；共享长期设备 token；显式开启完全访问后只共享短期单次秘密。保留第一项降级路径，采用第三项建议插入；第二项会扩大扩展权限与撤销后的暴露面，拒绝。
- Extends：MADR-029 的默认不联网路径，增加由本人主动开启系统“完全访问”的可选建议插入能力。未开启时不联网、不访问共享草稿，保留切回系统键盘。
- Evidence：Apple 官方 Custom Keyboard 文档明确：默认键盘没有网络权限，也不能与主 App 共享容器；`RequestsOpenAccess` 可开启相关能力，最终由用户控制。
- Decision：主 App 配对、选择照片/输入文字、分析与编辑。长期设备令牌只存主 App Keychain。共享容器仅存本人批准的草稿与 30 秒、单次兑换秘密，采用完整文件保护并排除备份。键盘仅在点击确认人物并插入时联网兑换，不上传按键或宿主文本。
- Server Contract：兑换重新检查设备撤销、票据、人物、关系与档案修订；共享文本不可替换服务器已批准草稿。消费前移除本机共享文件，失败需重新准备。服务重启和撤销立即阻止后续兑换。
- Editor Contract：请求前后检查 `documentIdentifier` 与扩展生命周期；不触发发送。iOS 无法可靠辨认同 App 的聊天人物，始终本人确认。安全字段由系统接管。
- Verification：短授权不可当设备令牌使用；篡改草稿、重放、过期和撤销测试；Mac 构建、Simulator 核心测试；真机授权/共享容器/平台插入另验。
- Consequence：30 秒授权增加返回操作的时间压力，需试点衡量。完整中文输入继续交还系统键盘，不把建议扩展称为全功能拼音输入法。

- Status：ACCEPTED WORKING BASELINE。
- Context / Options：代码量占比、主观完成百分比、按需求对应测试和使用证据关闭。选择第三项；前两项无法表示未知环境和真人观察的剩余风险。

- Critical Path：双端稳定性/签名与真实模型质量 → 六个 OS×平台组合 → 3 人×7 天排障 → 修正并扩展 3 人 → 发布评审。开发和黄金集工作可交叉进行，但没有设备、合法样本和签名时不能关闭相应验收。

- Guardrail：模型评分与机械检查不可相互替代；模型调用使用真实 usage 记录时延和 token，价格没有核验时不编造费用。自动规则不能证明关系因果收益。
