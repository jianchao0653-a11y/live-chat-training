# 小米手机首次测试：v0.15.1

> 历史版本指南。当前采用多机型、多 Android 版本验收，小米仅为首个真机样本；最新范围、流程及未完成项见 [v0.17.3 兼容记录](../07_reviews/V0_17_3_COMPATIBILITY.md)。请勿把下方旧版本步骤当作当前唯一支持配置。

当前仅确认你使用小米手机，具体型号与 HyperOS/MIUI 版本尚未登记。本指南不代表该真机已验收。建议先用合成文字完成中文输入与规则建议，再接真实模型。

## 1. 安装和中文输入

电脑上的 APK：`output/native/conversation-lens-0.15.1-debug.apk`。用 USB 文件传输复制到手机“下载”目录，从手机文件管理器打开安装，按系统提示允许本次安装来源。这个包是本项目调试测试包。

打开“观微输入法”，依次点 **1 · 在系统设置中启用**、**2 · 选择观微输入法**，选“观微简体拼音·测试”。直接在 App 的练习框试打 `nihao`、`zhongguo`、`xiexie`，检查候选选择、退格、英文/符号和“切回熟悉的输入法”。离线中文输入不需要电脑连接或模型密钥。

## 2. 启动电脑服务

在电脑 PowerShell 执行，窗口保持打开：

```powershell
Set-Location 'D:\聊天辅助'
npm.cmd start
```

电脑打开 http://localhost:4317 ，选择一个主播配置并新建名为“合成测试人物”的关系，平台和关系阶段选择有效选项。然后到“设置与数据 → 手机设备连接”生成六位配对码。

模型密钥当前尚未配置，先用规则试算；截图 OCR 与 GPT 分析需要另外在电脑设置中配置可用模型与密钥，调用会计费。

## 3. USB 连接和配对

小米设置中打开“我的设备/关于手机 → 全部参数与信息”，连续点击“OS版本/MIUI版本”，直到提示进入开发者模式；再到“更多设置 → 开发者选项”开启 **USB 调试**。不同系统版本名称可能略有差异。

手机通过 USB 连接电脑，在手机确认信任这台电脑。另开一个 PowerShell：

```powershell
Set-Location 'D:\聊天辅助'
& .\runtime\android-tools\sdk\platform-tools\adb.exe -d reverse tcp:4317 tcp:4318
```

`-d` 选择唯一的 USB 真机，不连接项目模拟器；电脑上同时连接多台真机会报错，此时须指定本人确认的设备序列号。命令没有输出通常表示设置成功。

手机打开观微 → **连接分析服务**，服务地址填写 **http://127.0.0.1:4317**，输入电脑生成的六位码，点 **配对连接**。看到“已连接 · 主播 …”后继续。这里的 USB 转发把手机 4317 连到电脑原生专用端口 4318；电脑管理网页仍使用 4317。拔线或服务重启后需重新建立相应连接/配对。

## 4. 完成一轮合成建议

在备忘录的普通文字输入框中调出观微键盘，点 **建议**。选择刚才的合成人物，填入：

```text
对方：今天加班很累，想安静休息。
我：那你先休息一下。
```

选择 **本机服务规则试算**，核对人物与片段后勾选批准，点击 **分析已批准片段**。审阅候选、修改草稿，点 **保留草稿并返回原聊天**，再点击键盘上的人物确认插入按钮。检查文字只进入输入框，没有自动发送。

再打开建议页，点 **断开并清除本机连接**，检查原片段、人物和上次反馈不再显示。系统旋转后也不应恢复旧片段。规则试算只验证操作流程，不代表 GPT 质量。

基础流程通过后再分别测试微信、抖音、快手的输入框；每个平台单独记录结果，先不要使用真实客户聊天或发送测试内容给别人。

## 5. 结束和常见问题

- 显示 `unauthorized`：手机解锁，确认 USB 调试授权；显示 `no devices`：检查数据线及 USB 调试连接。
- 配对失败：确认电脑服务窗口仍开着，重新执行转发；配对码两分钟有效，过期后重新生成。
- 输入法启用后仍是原键盘：回观微点击“2 · 选择观微输入法”，或使用系统键盘切换按钮。
- 需要截图/模型：完成配置前先粘贴文字并选规则试算。

结束后在电脑“设置与数据”撤销本设备授权，并执行：

```powershell
& .\runtime\android-tools\sdk\platform-tools\adb.exe -d reverse --remove tcp:4317
```

手机关闭 USB 调试，按需切回原输入法。反馈时记录手机型号、HyperOS/MIUI与Android版本、测试App版本、失败步骤和提示文字；不要发送配对码、密钥或真实聊天内容。
